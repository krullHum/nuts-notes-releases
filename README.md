# Nuts Notes

Notas em Markdown, guardadas no seu computador e organizadas por tags, com Biblioteca de PDF/EPUB e sincronização
entre aparelhos criptografada de ponta a ponta.

## Baixar

Em [Releases](../../releases/latest), baixe o arquivo do seu sistema:

| Sistema | Arquivo |
| --- | --- |
| Windows | `Nuts-Notes-Setup-<versão>.exe` |
| Mac (Apple Silicon e Intel) | `Nuts-Notes-<versão>-mac.dmg` |
| Android | `NutsNotes-Android.apk` |

### Windows

Siga o passo a passo do instalador. Depois disso o app se atualiza sozinho (Configurações › Sobre › Verificar
atualizações). O Windows pode mostrar o aviso do SmartScreen porque o instalador ainda não tem certificado de
assinatura ("Mais informações" › "Executar assim mesmo").

### Mac

1. Abra o `.dmg` e arraste o Nuts Notes para a pasta Aplicativos.
2. Abra o Nuts Notes. Na primeira vez, o macOS avisa que não pode verificar o app, porque ele ainda não tem a
   assinatura da Apple. Clique em "Concluído".
3. Abra Ajustes do Sistema › Privacidade e Segurança, desça até o aviso do Nuts Notes, clique em "Abrir Mesmo
   Assim" e confirme. Daí em diante ele abre normalmente.

Quando sai uma versão nova, o app avisa em Configurações › Sobre. Baixe o `.dmg` novo e arraste o app de novo para
Aplicativos. As notas continuam onde estão.

### Android

No celular, abra o `NutsNotes-Android.apk` e toque no arquivo baixado. Na primeira vez, o Android pede para
permitir que o navegador instale apps desconhecidos.

Este repositório guarda só os instaladores.
