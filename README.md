# Nuts Notes

Notas em Markdown, guardadas no seu computador e organizadas por tags, com Biblioteca de PDF/EPUB e sincronização
entre aparelhos criptografada de ponta a ponta.

## Baixar

Em [Releases](../../releases/latest), baixe `Nuts-Notes-Setup-<versão>.exe` e siga o passo a passo do instalador.
Depois disso o app se atualiza sozinho (Configurações › Sobre › Verificar atualizações).

Este repositório guarda só os instaladores; o Windows pode mostrar o aviso do SmartScreen porque o instalador ainda não
tem certificado de assinatura ("Mais informações" › "Executar assim mesmo").
